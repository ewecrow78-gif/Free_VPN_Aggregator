# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| V3      | :white_check_mark: |
| V2      | :x:                |
| V1      | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please open an issue with the label `security`, or contact the maintainers privately if the vulnerability is sensitive.

Please provide detailed steps to reproduce the vulnerability. We will attempt to address it as soon as possible.
